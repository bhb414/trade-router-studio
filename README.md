# Trade Router Studio

Trade Router Studio는 개인 컴퓨터에서 Python 자동매매 프로젝트를 실행하고
브라우저로 관리하는 로컬 웹 작업공간이다. 사용자가 실제로 여는 프로그램은
Studio 하나이며, Trade Router는 내부 라이브러리로 동작한다.

## 사용 경험

```text
run.cmd 실행
    → 로컬 서버 시작
    → 브라우저에서 작업공간 열기
    → .py 전략 작성·실행·중지
    → 로그·보유·주문·체결 확인
```

- 전략은 일반 `.py` 파일이며 웹 편집기와 외부 편집기에서 함께 사용할 수 있다.
- 한 컴퓨터에서 한 개의 Studio 프로세스가 증권사 연결과 전략 실행을 관리한다.
- 별도 Router 콘솔이나 운영용 데몬 화면을 사용자에게 노출하지 않는다.
- 계좌 설정, 전략, 로그와 매매 기록은 프로그램 코드와 분리해 보존한다.
- 첫 화면은 스크립트 목록, 편집기, 실행 버튼과 로그로 단순하게 구성한다.

## GitHub 업데이트

Studio는 `bhb414/trade-router-studio`의 최신 GitHub Release를 확인한다.
새 버전이 있으면 웹 화면에서 업데이트를 시작하고 다음 순서로 처리한다.

1. 새 버전과 검증 파일을 GitHub에서 내려받는다.
2. 실행 중인 전략과 로컬 서버를 정상 종료한다.
3. 프로그램 코드와 내부 라이브러리만 교체한다.
4. 사용자 전략·설정·기록은 유지한다.
5. 새 버전으로 다시 실행하고, 실패하면 이전 버전으로 복구한다.

사용자가 `git pull`, Python 패키지 명령 또는 설치 프로그램을 직접 다룰 필요가
없도록 한다.

## 저장소 경계

- `trade-router`: 증권사 통합 Python 라이브러리
- `trade-router-studio`: 로컬 웹 UI, 전략 파일, 실행 수명주기, 업데이트

이 저장소는 기존 구현을 제거한 뒤 새 구조로 다시 시작했다.
